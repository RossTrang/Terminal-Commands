A quick reference list of useful terminal commands that can be imported into the [Cheaty](https://cinnamon-spices.linuxmint.com/applets/view/285) desktop applet. While most are already included in distros by default, some may need to be installed via the command line "sudo apt install xxxxxxx".

The folder should be placed in `~/.local/share/cinnamon/applets/cheaty@centurix/refdocs` or your defined cheatsheetFolder if you have configured an alternative.

More entries can be added by following the JSON format of the existing file.
